\begin{abstract}
Millimeter-wave (mmWave) radar captures are expensive to collect, tightly coupled to a specific antenna configuration, and difficult to reuse across downstream tasks that require different signal processing chains. Novel view synthesis (NVS), rendering accurate radar signals from arbitrary sensor poses given a sparse set of real captures, would provide an explicit and compressible scene representation, complex-valued output compatible with any downstream processing pipeline, and a data augmentation engine for training perception models. Existing radar NVS methods adapt vision primitives (neural radiance fields, 3D Gaussians) to render power-only range--azimuth images with opaque learned features, discarding phase and preventing use in applications that require complex data. Physics-based inverse renderers produce complex signals with interpretable materials but rely on Monte Carlo ray tracing too slow to optimize across the multiple viewpoints that NVS demands.
%
We present mm3DGS, a physics-based differentiable point renderer that synthesizes complex range profiles from novel sensor poses. mm3DGS uses oriented 3D points with per-point ITU-R P.2040 material parameters as a graphics primitive native to the radar forward model: for each transmitter--receiver pair, a physically-based bidirectional scattering distribution function is evaluated at the deterministic incidence and observation angles, and the resulting complex phasor is splatted into range-profile bins via a precomputed Hann-windowed point spread function on a LiDAR-derived geometric scaffold. This factorized pipeline, accelerated by fused CUDA kernels, processes 20k scene points per iteration and trains in ${\sim}$2.3 minutes (500 iterations on 8 training viewpoints), making multi-viewpoint optimization tractable where Monte Carlo ray tracing at 24k points requires ${\sim}$20 minutes per single viewpoint.
%
On six outdoor ColoRadar scenes with one held-out interpolated viewpoint per scene (eight bracketing training viewpoints, single chirp loop), mm3DGS achieves \textbf{0.593} mean Pearson correlation on novel-view range--azimuth magnitudes, more than $1.7\times$ the next-best baseline (RadarSplat 0.339, Radar Fields 0.120, DART 0.099). Because the output is complex-valued, standard FFT pipelines convert range profiles to arbitrary radar products (range--azimuth, range--Doppler, raw ADC) without retraining.

\end{abstract}
